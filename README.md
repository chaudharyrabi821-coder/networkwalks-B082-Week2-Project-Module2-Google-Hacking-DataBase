# Screenshots Guide

Drop your screenshots into this folder using the **exact filenames** below so they render correctly in the main `README.md`.

| Filename | What to capture |
|---|---|
| `step1-exploitdb-home.png` | The exploit-db.com homepage/exploit listing, freshly loaded. |
| `step2-ghdb-menu.png` | The left sidebar expanded, with the cursor/highlight on the **GHDB** menu item. |
| `step3-ghdb-search.png` | The GHDB page with a keyword (e.g. `cam`) typed into the quick-search box and results showing. |
| `step4-copy-dork.png` | The right-click context menu open over a dork entry, showing the "Copy" option. |
| `step5-google-search.png` | Google's search results page for the pasted dork. |
| `step6-verify-result.png` | A verified live result opened in-browser (e.g. an actual camera feed or directory listing loading). |
| `task1-example-camera.png` | A clean, full-window shot of one confirmed live camera interface for the Task 1 example callout. |

## Tips for clean screenshots

- Crop out personal bookmarks bar, unrelated browser tabs, and taskbar/system tray icons.
- Blur or redact your own IP/account details if visible in the browser chrome.
- Keep a consistent browser window size across screenshots for a uniform look in the README.
- Use `.png` for crisp text; avoid `.jpg` for anything with UI text in it.
