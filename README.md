## Tips for clean screenshots

- Crop out personal bookmarks bar, unrelated browser tabs, and taskbar/system tray icons.
- Keep a consistent browser window size across screenshots for a uniform look.
- Use `.png` for crisp UI text; avoid `.jpg` for anything with small text in it.
