## 🎨 Tips for Clean, Consistent Screenshots

| ✅ Do | 🚫 Avoid |
|---|---|
| Keep a consistent browser window size across all 4 shots | Mixing window sizes — breaks the side-by-side layout |
| Crop out bookmarks bar, unrelated tabs, taskbar/tray icons | Leaving personal info or unrelated tabs visible |
| Save as **`.png`** for crisp, readable UI text | Using `.jpg` — compression blurs small text |
| Zoom browser to 100% before capturing | Capturing at odd zoom levels that skew proportions |
